# 编码规范：文件分区与代码风格

> 适用范围：本仓库 `User/`（Bsp、Common、Service、App、Config）下的手写模块，以及 `Core/Src` 中由用户编写的驱动函数（`Drv_*`）。
> CubeMX 生成的 `MX_*` / `HAL_*` 框架代码沿用其自带的 `/* USER CODE BEGIN/END */` 体系，不强制套用本规范的分区编号；但用户写在 `USER CODE` 区内的函数应遵循本规范的命名与注释要求。
>
> 本文档是团队约定的单一来源（Single Source of Truth）。新建/修改文件时以此为准。

---

## 1. 总则

- **公私分明**：`.h` 只暴露对外契约（依赖、对外宏/类型/变量声明、接口声明）；实现细节（私有宏/类型/变量/函数）一律下沉到 `.c`。
- **最小依赖（IWYU, Include What You Use）**：用到谁就直接包含谁的头，不依赖"别的头帮我捎带"。
- **全局变量克制**：优先用 `get/set` 接口替代对外全局变量；确需对外的变量集中在指定分区并加 `g_` 前缀。
- **一致性优先**：同类问题在全工程用同一种写法，宁可统一也不追求局部最优。
- **每个文件、每个对外接口都带 Doxygen 注释**。

## 2. 命名约定

### 2.1 文件名
- 模块源码：小写 + 下划线，如 `motor_service.c/.h`、`simulink_protocol.c/.h`、`common.c/.h`、`bsp.c/.h`、`config.h`。
- 一个模块一对 `.h/.c`（纯配置/纯声明模块可只有 `.h`，如 `config.h`）。

### 2.2 头文件保护宏（include guard）
- 形如 `文件名大写_H`，如 `MOTOR_SERVICE_H`、`STATE_MACHINE_H`。
- **禁止**前导/双下划线（`__XXX__`、`_XXX`）——属 C 标准保留标识符。
- 结尾 `#endif` 后注明对应宏名：`#endif /* MOTOR_SERVICE_H */`。

### 2.3 函数前缀（按模块）
| 模块 | 路径 | 前缀 | 示例 |
|------|------|------|------|
| Bsp | `User/Bsp` | `Bsp_` | `Bsp_Init`、`Bsp_DelayMs` |
| Common | `User/Common` | `Cmn_` | `Cmn_RFQ_Push`、`Cmn_CalcCRC8` |
| Service | `User/Service` | `Svc_` | `Svc_MotorService_GetFeedbackData` |
| App | `User/App` | `App_` | `App_StateMachine_MainLoop` |
| Driver（用户驱动层，位于 `Core/Src` 的 USER 区） | `Core/Src` | `Drv_` | `Drv_PWM_Enable`、`Drv_ADC_Motor_RawData_Read` |
| CubeMX 生成 | `Core/Src` | `MX_` / `HAL_` | `MX_TIM1_Init` |

- **对外接口**（`.h` 第 5 区声明）必须使用模块前缀：`Bsp_`、`Cmn_`、`Svc_`、`App_`、`Drv_` 等。
- **文件内 `static` 私有函数**不加上述模块前缀；可用语义化短名或子域前缀（如 `EncoderProtocol_ParseFrame`、`RFQ_Memcpy`、`EncoderUart_MergeStickyFlags`），模块边界由文件名与 `static` 表达。

### 2.4 类型 / 枚举 / 宏
- **类型**：大驼峰 + `_t` 后缀。如 `Status_t`、`MotorFeedbackData_t`、`ControlObject_t`、`EncoderDual_t`。
- **枚举成员**：全大写下划线，带语义前缀。如 `STATUS_OK`、`MOTOR_SVC_ERR_PARAM`、`SIMULINK_PROTOCOL_OK`、`PRJ_ENABLE`。
- **宏**：全大写下划线。如 `DEBUG_PRINTF`、`SPEED_PERMYRIAD_MAX`、`ENCODER_FRAME_LENGTH_BYTES`。

### 2.5 变量（匈牙利前缀，描述"类型/作用域"）
| 前缀 | 含义 | 示例 |
|------|------|------|
| `u8 / u16 / u32` | 无符号整型（位宽） | `u16Len`、`u32FrameDtUs` |
| `s16 / s32` | 有符号整型（位宽） | `s16Pwm`、`s32MotorSpeed` |
| `f` | 浮点 | `fVadc`、`fDtSec` |
| `stru` | 结构体实例 | `struCtrl`、`struFb` |
| `en` | 枚举实例 | `enObject` |
| `a` + 类型 | 数组 | `au8RxBuf`、`au16RawAdc` |
| `p` + 类型 | 指针 | `pu8Buf`、`ps32RawAdc`、`pstruSrc` |
| `g_` | **跨文件**全局变量（`.h` 可 `extern`，或被其他 `.c` 引用） | `g_au8DebugRxBuff` |
| `s_` | **文件级** `static`（模块私有，仅本 `.c` 可见） | `s_u32MotorSlotSeq`、`s_enControlObject`、`s_au16ADC1VolValue` |
| `ls_` | **函数内** `static` 局部变量（跨调用驻留，如 DMA 缓冲、查表） | `ls_actual_tbl`、`ls_au8FeedbackTxBuf` |

> 约定（重要）：**`g_` / `s_` / `ls_` 按作用域分层，不看生命周期**（后两者存储期同为整个程序运行期）。
> - `g_`：仅用于**跨文件**共享；能封装为 `get/set` 接口的优先不用 `g_`。
> - `s_`：写在**函数外**且带 `static` 的模块私有状态，放在 `.c` 第 5 区「私有变量」。
> - `ls_`：写在**函数内**且带 `static` 的局部驻留变量（DMA 异步缓冲、函数内查表等）。
> - 函数内普通局部变量（栈上）：**不加** `g_`/`s_`/`ls_`，仅用 `au8`/`u16`/`stru` 等类型前缀。

决策简表：

```
定义在函数外？
├─ 跨文件（extern / 他 .c 引用）  → g_，放第 4 区「对外变量」
└─ static，仅本 .c               → s_，放第 5 区「私有变量」

定义在函数内？
├─ 普通局部（栈）                 → 无前缀
└─ static 局部                   → ls_
```

## 3. `.h` 头文件模板与分区

```c
/**
 * @file    xxx.h
 * @brief   <一句话职责>
 * @details 模块路径：`User/Xxx`。<对外/对下依赖、与 common 类型对齐、关键约束等>
 */

#ifndef XXX_H
#define XXX_H

#ifdef __cplusplus
extern "C" {
#endif

/* ======================== 1. 头文件依赖 ======================== */
/* 仅包含"对外接口签名/对外类型"所必需的头；实现细节用头不在此处 */

/* ======================== 2. 宏定义（对外可见） ======================== */

/* ======================== 3. 类型定义 ======================== */

/* ======================== 4. 对外变量声明 ======================== */
/* 默认应为"无"；确需对外的全局变量在此 extern 声明 */

/* ======================== 5. 接口函数声明 ======================== */

#ifdef __cplusplus
}
#endif

#endif /* XXX_H */
```

规则：
- 必含 `extern "C"` 包裹（即使当前为纯 C 工程，统一规范、为将来 C++ 调用留余地，零运行期成本）。
- 各分区即使为空也保留标题并写 `/* 无 */`，便于一眼确认"确实没有"而非"漏写"。
- "头文件依赖"只放**对外契约**需要的头；仅实现需要的头放进 `.c`（见第 6 节）。

## 4. `.c` 源文件模板与分区

```c
/**
 * @file    xxx.c
 * @brief   <一句话职责>
 * @details <私有头依赖说明、关键算法/时序约束、并发注意等>
 */

/* ======================== 1. 头文件引用 ======================== */

/* ======================== 2. 私有宏定义 ======================== */

/* ======================== 3. 私有类型定义 ======================== */

/* ======================== 4. 对外变量定义 ======================== */

/* ======================== 5. 私有变量 ======================== */

/* ======================== 6. 私有函数声明 ======================== */

/* ======================== 7. 接口函数实现 ======================== */

/* ======================== 8. 私有函数实现 ======================== */

/* ======================== 9. HAL 回调函数实现 ======================== */
```

规则：
- 段 6 先**前向声明**所有私有函数，段 8 再实现——这样实现顺序可按逻辑组织，不受调用先后约束。
- 段内允许再分子节，如 `bsp.c` 的 `7.1 系统服务 / 7.2 CRC16 / 7.3 printf 重定向`。
- 编号连续保留，空段写 `/* 无 */`。
- **第 9 区**专用于 `HAL_*Callback` / `HAL_*_Callback` 等 HAL 弱符号回调覆写，放在 `.c` 文件**最末尾**（`USER CODE BEGIN 1` 或 `USER CODE BEGIN 2` 尾部），与段 7/8 的用户驱动实现分离。

### 4.1 特例：`Core/` CubeMX 文件的 USER 区映射

CubeMX 生成的 `MX_*` / `extern` 句柄 / `HAL_*_MspInit` 等框架代码**不改动、不套分区**；用户手写内容**集中**写入下列单一 USER 槽位，其它 USER 槽（`Private defines`、`Prototypes`、`PD`、`PV`、`PFP` 等）保持空白：

**`Core/Inc/*.h`**

| CubeMX 标记 | 分区 | 内容 |
|-------------|------|------|
| **`USER CODE BEGIN Includes`**（唯一用户槽） | 1~5 | 头文件依赖、对外宏、类型、`extern` 对外变量、接口声明 |

**`Core/Src/*.c`**

| CubeMX 标记 | 分区 | 内容 |
|-------------|------|------|
| **`USER CODE BEGIN 0`**（唯一声明区） | 1~6 | 额外 `#include`、私有宏、类型、`g_` 对外变量、`s_` 私有变量、私有函数前向声明 |
| `USER CODE BEGIN 1` / `4`（文件末尾） | 7 | `Drv_*` 等用户驱动接口实现 |
| 同上区域后半段 | 8 | `static` 私有函数实现 |
| `USER CODE BEGIN 1` / `2` **文件末尾** | 9 | `HAL_*Callback` 等 HAL 回调 |

无用户代码时：`Includes` / `USER CODE 0` 内 **1~6 区**、以及文件末尾 `USER CODE 1` / `2` / `4` 内 **7~9 区**，均须保留分区标题；空段统一写 `/* 无 */`，不得省略整段。

## 5. 特例：配置模块 `config.h`

`config.h` 为"用户开关单一入口"，不套用第 3 节的 1–5 分区，改用开关三段：

```c
/* ==================== 1. 编译开关（Compile） ==================== */
/* 决定条件编译走向、构建变体（影响最终生成的代码） */

/* ==================== 2. 功能开关（Feature） =================== */
/* 使能/失能某项运行期功能或行为分支 */

/* ===================== 3. 调试开关（Debug） ==================== */
/* 仅用于开发调试（如串口打印），发布前宜收敛 */
```

约定：
- 全工程用户开关只在此 `#define`，其他文件只 `#if`/`#ifdef` **使用**、不重复定义。
- 需要这些开关的文件 `#include "config.h"`（或经已包含它的模块头透传）。

## 6. 头文件依赖原则

- **IWYU**：`.c`/`.h` 各自直接包含自己用到符号的来源头，不依赖传递包含。
- **公私分流**：对外接口签名/类型需要的头放 `.h` 的"头文件依赖"段；仅实现需要的头放 `.c` 的"头文件引用"段。
- **包含顺序建议**：标准库（`<stdint.h>`/`<stddef.h>`/`<stdio.h>`）→ 本工程公共头（`config.h`/`common.h`）→ 本模块/驱动头。
- 避免对外头互相包含形成隐式强耦合；开关类只走 `config.h`。

---

## 7. 注释规范（Doxygen）

- 每个文件头：`@file` / `@brief` / `@details`。
- 每个对外函数、以及逻辑复杂的私有函数：`@brief`，必要时 `@param`/`@param[out]`/`@return`/`@note`/`@details`。
- 注释解释**意图、约束、坑**，不复述代码字面动作（避免 `i++; // i 加一` 式废话）。
- `@param` 名必须与形参名一致；写错的多项式/范围等技术性注释要与实现严格对齐。

## 8. 通用编码约定

### 8.1 返回值
- 通用"成功/失败"用 `Common` 的 `Status_t`（`STATUS_OK` / `STATUS_ERROR` / `STATUS_BUSY` / `STATUS_TIMEOUT`）。
- 需要区分多种失败原因的模块，定义自己的结果枚举（如 `MotorServiceResult_t`、`SimulinkProtocolResult_t`），并提供到 `Status_t`/上层枚举的映射函数。
- 使能/失能状态用 `FunctionalState_t`（`PRJ_ENABLE` / `PRJ_DISABLE`）。

### 8.2 调试打印
- 统一用 `BSP_LOG_PRINTF(...)`（定义于 `bsp.h`，受 `config.h` 的 `DEBUG_PRINTF` 约束）。
- `DEBUG_PRINTF=0` 时调用点连同参数格式化被整条编译删除，**热路径/中断零开销**。
- 例外：致命兜底（如 `Error_Handler`）仍用裸 `printf`，不走该宏。

### 8.3 编译期检查
- 优先用 `#error`（开关组合非法）、`_Static_assert`（帧长、枚举范围、结构体大小）在编译期暴露问题，而非运行期才发现。

### 8.4 中断/并发
- 中断回调内只做最短必要工作；与中断共享的变量加 `volatile`，跨上下文共享的临界区做关中断保护（参考 `Bsp_Crc16Modbus_Byte`）。

## 附录 A：最小 `.h`/`.c` 成对示例

`example_module.h`
```c
/**
 * @file    example_module.h
 * @brief   示例模块：演示对外接口分区
 * @details 模块路径：`User/Example`。仅依赖 common.h 的 Status_t。
 */

#ifndef EXAMPLE_MODULE_H
#define EXAMPLE_MODULE_H

#ifdef __cplusplus
extern "C" {
#endif

/* ======================== 1. 头文件依赖 ======================== */
#include <stdint.h>
#include "common.h"

/* ======================== 2. 宏定义（对外可见） ======================== */
#define EXAMPLE_MAX_COUNT   100U

/* ======================== 3. 类型定义 ======================== */
typedef struct
{
    uint16_t u16Count;
} ExampleData_t;

/* ======================== 4. 对外变量声明 ======================== */
/* 无 */

/* ======================== 5. 接口函数声明 ======================== */
/**
 * @brief  读取示例数据
 * @param[out] pstruOut 输出缓冲区
 * @return STATUS_OK 成功；STATUS_ERROR 参数非法
 */
Status_t Example_GetData(ExampleData_t *pstruOut);

#ifdef __cplusplus
}
#endif

#endif /* EXAMPLE_MODULE_H */
```

`example_module.c`
```c
/**
 * @file    example_module.c
 * @brief   示例模块实现
 * @details 仅 #include 自身头与所需实现头。
 */

/* ======================== 1. 头文件引用 ======================== */
#include "example_module.h"

/* ======================== 2. 私有宏定义 ======================== */
#define EXAMPLE_DEFAULT_COUNT   0U

/* ======================== 3. 私有类型定义 ======================== */
/* 无 */

/* ======================== 4. 对外变量定义 ======================== */
/* 无 */

/* ======================== 5. 私有变量 ======================== */
static uint16_t s_u16LastCount = EXAMPLE_DEFAULT_COUNT;

/* ======================== 6. 私有函数声明 ======================== */
static uint16_t Example_Clamp(uint16_t u16Value);

/* ======================== 7. 接口函数实现 ======================== */
Status_t Example_GetData(ExampleData_t *pstruOut)
{
    if (pstruOut == NULL)
    {
        return STATUS_ERROR;
    }
    pstruOut->u16Count = Example_Clamp(s_u16LastCount);
    return STATUS_OK;
}

/* ======================== 8. 私有函数实现 ======================== */
static uint16_t Example_Clamp(uint16_t u16Value)
{
    return (u16Value > EXAMPLE_MAX_COUNT) ? EXAMPLE_MAX_COUNT : u16Value;
}
```
