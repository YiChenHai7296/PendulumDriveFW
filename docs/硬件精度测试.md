# 1  测试目标
本文档记录摆系统通用驱动板在 V1.2 测试固件 下的硬件精度验证，重点确认以下两项是否满足控制与反馈需求：
## 1.1  PWM 给定占空比测试
验证上位机给定占空比经单片机 PWM 映射后，电机 H 桥两侧实际输出占空比是否与给定值一致，为后续占空比标定与转速控制提供依据。

## 1.2  ADC 精度测试
验证两路模拟采样链路的换算精度：
- 电机电流（ADC1 / ADC2）：PWM 高、低电平中心点采样；
- 软尺摆幅电压（ADC3）：外部电压输入采样。

对应系统需求：电流误差 < 10 mA，摆幅电压误差 < 10 mV。

# 3  测试方法
## 3.1  PWM给定占空比测试
从图示引脚飞出两根短测量线，接入差分表笔进行占空比测量，观察实际给出**PWM占空比**是否与**上位机给定**一致。

**目的：** 对比「上位机给定占空比」与「示波器实测占空比」，以说明拟合函数的拟合精度。

**步骤：**
1. 在 H 桥输出端（图示引脚）飞出两根短测量线；
2. 差分表笔接入，测量电机两侧实际 PWM 占空比；
3. 上位机按 0.1%～99% 给定多组占空比，记录实测值并计算误差。

### 3.2.1  电机ADC测量
**换算公式：**
$$I_{电机}=\frac{V_{adc}−1.6 V}{41×R_{14}}$$​

**接线：** 
	图示采样回路处串联电流表和功率电阻，由表计读数得到实际电流；与单片机 ADC 换算电流对比。

# 4  测试结果
## 4.1  PWM给定测试
### 4.1.1  数据整理
![图12 PWM测试结果数据整理](images/硬件精度测试images/图12-PWM测试结果数据整理.png)
### 4.1.2  测试结论

| 给定占空比区间   | 实测表现        | 相对误差（典型）                   |
| --------- | ----------- | -------------------------- |
| 0.1%～0.2% | 实测为 0，无有效输出 | 死区                         |
| 0.3%～1.0% | 有输出但偏差较大    | 约 ±30%～±40%                |
| ≥ 1.1%    | 跟踪明显改善      | 多数 < 3%                    |
| ≥ 2.0%    | 精度稳定        | 多数 < 1%（如 10% 给定误差约 0.13%） |
| 99% 给定    | 实测约 94.84%  | 受固件最大占空比 95% 限制            |

1. 低占空比死区明显： 给定 ≤ 0.2% 时实测为 0，与固件死区阈值（约 0.08%）及驱动芯片、H 桥开启特性一致；0.3%～1.0% 区间误差仍较大，不宜作为精确调速区。
2. 有效调速区精度良好： 给定 ≥ 2.0% 时，相对误差多数 < 1%，满足万分之一给定精度下的实际控制需求。
3. 上限受软件限制： 给定 99% 时输出约 94.84%，与程序 95% 占空比上限 一致，属预期行为。

**结论：** PWM 映射在 ≥ 2% 占空比 范围内可用；低占空比区需依赖标定表/死区补偿，与正式固件 `MOTOR_PWM_USE_FIT_MAPPING` 策略一致。

## 4.2  ADC精度测试
### 4.2.1  数据整理
![图13 ADC测试结果数据整理](images/硬件精度测试images/图13-ADC测试结果数据整理.png)

### 4.2.2  测试结论
1. 电机电流： 相对误差 < 1%，绝对误差最大约 6.5 mA（50% 工况），满足 < 10 mA 指标。
2. 软尺摆电压： 测试点误差 < 2 mV，相对误差 < 0.1%，满足 < 10 mV 指标。

**结论：** 两路 ADC 采样链路（含隔离放大、偏置与换算公式）精度达标，可作为闭环反馈与软尺摆模式摆幅上报的可靠数据来源。
