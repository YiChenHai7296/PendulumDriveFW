## 4. EncoderTrigger_Send 注释块（约第 856–861 行）

**查找：**
```
  * @brief  ????????3?4?5?? DMA ????? 0x02?? TIM1 ???????
  * @note   ??3?4?5??? DMA ??????????????? DMA ?????????
  */
void EncoderTrigger_Send(void)
{
  static uint8_t u8TimedSendByte = 0x02;  /* ??????? DMA ????????? */
```

**替换为：**
```
  * @brief  定时向串口 3、4、5、2 依次 DMA 发送单字节 0x02（在 TIM1 定时中断中调用）
  * @note   注意 3/4/5 共用一个静态缓冲；DMA 未完成时勿重复调用
  */
void EncoderTrigger_Send(void)
{
  static uint8_t u8TimedSendByte = 0x02;  /* 单字节 0x02 用于 DMA 触发编码器 */
```

（若你当前文件是“?????” 等变体，可只替换 @brief / @note 和行内注释三处为上面对应三行。）

## 保存为 UTF-8

- **VS Code / Cursor**：右下角点编码 → “通过编码保存” → 选 **UTF-8**。
- **Keil**：建议用 VS Code 做注释替换并保存为 UTF-8 后，再在 Keil 中打开或替换文件。

完成上述替换并保存为 UTF-8 后，即得到带完整中文注释的 usart.c；可另存为 `usart_完整代码_UTF8注释.c` 作为副本。
